# Student Placement & Salary Prediction

## About Project
This project is based on student placement and salary prediction using Machine Learning.

It analyzes student data and shows useful information through an interactive dashboard.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## Machine Learning Models
- Linear Regression
- Decision Tree
- Random Forest

## Dashboard Features
- Student placement analysis
- Placement status charts
- Model performance comparison
- Salary prediction using Random Forest
- Data visualization

## Project Structure
- `dashboard/` – Dashboard files
- `datasets/` – Dataset
- `notebook/` – Jupyter Notebook
- `models/` – Model-related files
- `main.py` – Main dashboard file
- `utils.py` – Helper functions
- `requirements.txt` – Required libraries

## How to Run

1. Install the required libraries:

```bash
pip install -r requirements.txt
```

2. Run the dashboard:

```bash
streamlit run main.py
```

## Note
The trained Random Forest model file is stored locally and is not included in this GitHub repository because of its large size.
